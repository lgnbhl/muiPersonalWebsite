# muiPersonalWebsite: Personal Site Generator Using 'muiMaterial'

Builds a personal website from YAML alone. Every element of every page
is a 'muiMaterial' component, from the app bar to the footer, with the
'head' metadata written at build time. A configuration file names the
sections; each section is a content file of projects, apps or talks; and
mui_create_site() writes a working site to start from. It is the
generator behind felixluginbuhl.com, and the functions themselves double
as worked examples of 'muiMaterial' in production.
